= ocp4_workload_external_odf - Configuration to setup OpenShift Data Foundation .

== Role overview

It configures ODF in external mode and configure the image registry in a PVC.

== NooBaa pvPool scaling

By default the role leaves the NooBaa backing store at the operator default.
If your cluster has more than 3 workers, set
`ocp4_workload_external_odf_noobaa_pv_pool_num_volumes` to match your worker
count so that Quay and other object storage consumers have enough capacity.

Set this in your AgnosticV catalog item:

[source,yaml]
----
# Tie pvPool size directly to the number of workers in the catalog item
ocp4_workload_external_odf_noobaa_pv_pool_num_volumes: "{{ worker_instance_count | int }}"
----
